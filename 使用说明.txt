鼠标点击次数记录  使用说明   by 黎修源
========================================

【启动】
双击 鼠标点击次数记录.exe → 会弹一次 UAC 询问管理员权限（同意才能统计游戏内点击，取消也能用，
只是游戏内不计数）→ 弹出统计窗口，右下角托盘出现图标，开始记录
（其他文件\启动.bat 效果相同；exe 移走后请连同「其他文件」文件夹一起移动）

【右下角托盘图标】
  左键单击（双击也行）：打开/唤回窗口（窗口被其他程序挡住时会自动置顶一下）
  右键单击           ：弹出菜单 → 控制面板（打开窗口） / 关闭程序（终止运行）
  鼠标悬停 ：显示「今日 N 次｜总计 N 次」
  提示：Windows 11 默认把新图标收进「^ 隐藏的图标」里，拖到任务栏上就会常驻显示

【窗口关闭行为】
  点窗口右上角叉号 → 询问「隐藏到后台」还是「完全退出」
  隐藏后程序继续记录，随时用托盘图标叫回来

【显示内容】
  今日      ：今天各按键的点击次数
  本周日均  ：本周（周一至今）平均每天点击次数
  近7天日均 ：最近 7 天平均每天点击次数
  总计      ：开始记录以来的累计点击次数
  按键明细  ：左键 / 右键 / 中键 / 侧键1 / 侧键2 / 合计
  说明：侧键1、侧键2 对应鼠标侧键（Windows 的 XBUTTON1 / XBUTTON2）

【开机自启动】
方式一：托盘右键菜单里点「开机自动启动」（推荐，可随时取消）
方式二：窗口里勾选「开机自动启动」复选框
方式三：双击 其他文件\设置开机自启动.bat  /  其他文件\取消开机自启动.bat
两种方式，程序会按当前权限自动选：
   · 有管理员权限 → 注册 Windows 计划任务（名字「鼠标点击次数记录」，「登录时」触发、
     勾选「使用最高权限运行」）。开机静默启动、不弹 UAC，游戏内点击也能统计
   · 没有管理员权限 → 退回注册表 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
     （能开机启动，但游戏内不计数；建议先点「以管理员身份重启」再勾选一次）
   · 开机时都是静默启动：只出现右下角托盘图标，不会弹窗口，点托盘图标才打开窗口
   · 自启动路径会自愈：每次打开程序都会把自己在注册表里的路径改成当前所在位置，
     所以整包挪到别的文件夹（甚至另一台电脑手动打开一次）后，自启动会自动恢复
   · 只要以管理员身份打开过一次，程序会自动把"注册表方式"升级成"计划任务·最高权限"，
     不需要你再手动勾选；状态栏会显示「自启动:计划任务(最高权限)」
   · 换电脑后第一次仍需手动打开一次程序，它才会把自启动项补写到新电脑的注册表里
   · 注意：同时存在多个副本时，最后打开的那个副本会接管自启动指向

【游戏里统计不到点击？】
  带内核反作弊的游戏（例如明日方舟：终末地，ACE 反作弊）以高权限运行，普通权限的程序
  收不到它们的鼠标输入，这是 Windows 的 UIPI 限制。解决：以管理员身份运行本程序
  （窗口右下角状态栏会显示「管理员权限」）。窗口标题下方状态栏若出现
  「⚠ 钩子疑似被拦截」，说明当时钩子确实没收到事件，日志在 tray.log。

【目录结构】
  鼠标点击次数记录.exe   主程序（单文件，免安装，不依赖 Python）
  使用说明.txt           本文件
  点击数据记录（勿删！！！）.json
                         ★ 点击数据存这里，每天一条，自动保存（最多丢 3 秒数据）
                         ★ 首次点击后自动生成，是你的历史记录，千万不要删
                         若放进去旧的 data.json，程序也会自动读取并在下次保存时改成新文件名
  其他文件\icon.ico      托盘与窗口图标
  其他文件\启动.bat      等价于双击 exe
  其他文件\设置开机自启动.bat / 取消开机自启动.bat   一键开关自启动
  其他文件\error.log     出错时才生成
  tray.log               托盘事件日志（排查托盘点击问题用，可随时删）
  说明：若本文件夹不可写（例如放进 C:\Program Files 或只读共享），数据与日志
        会自动改存到 %LOCALAPPDATA%\鼠标点击次数记录\，界面照常工作不会丢数据。

【资源占用】
  使用 Windows 底层鼠标钩子 (WH_MOUSE_LL)，回调只做计数并入队，不阻塞鼠标输入；
  空闲时 CPU 占用 ≈ 0%（开机后累计 CPU 时间通常不到 1 秒），内存约 50 MB，
  窗口隐藏后同样保持监听。
  任务管理器里会看到两个同名进程，这是单文件 exe 的正常现象（一个是解包引导，
  一个是主程序），只有主程序带窗口。

【卸载】
1. 双击 其他文件\取消开机自启动.bat（或用托盘菜单取消勾选）
2. 托盘右键 → 退出程序
3. 删除整个文件夹
