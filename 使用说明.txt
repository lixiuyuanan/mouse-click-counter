鼠标点击次数记录  使用说明   by 黎修源   v2.2.0
========================================

【启动 / 首次声明】
双击 鼠标点击次数记录.exe → 会弹一次 UAC 询问管理员权限（同意才能统计游戏内点击，取消也能用，
只是游戏内不计数）→ 首次使用先弹出「免责声明」，点「我已阅读并认可，继续使用」后进入统计窗口
（点「不同意并退出」则关闭程序；确认过一次后不再重复弹，开机静默自启也不弹）
→ 右下角托盘出现图标，开始记录
（config\启动.bat 效果相同；点击数据存在「文档」里，所以程序文件夹可以随时替换或整个删掉）

【窗口顶部快捷栏】
首页 / 设置 / 鼠标档案 / 关于，四个页面点击切换。窗口大小固定（切页不会变大变小），
当前页面内容超出窗口时，可用鼠标滚轮上下滚动查看。

【首页】
  顶部三个数字：今日点击 / 近7天日均 / 总点击次数
    · 亿级缩写：≥1亿显示「1.23 亿」，千万级显示「3456.8 万」，其余带千分位
    · 鼠标悬停在大数字上，可查看精确完整值
  按键明细表（列：按键 / 寿命 / 今日 / 近7天日均 / 总计）：
    · 行：左键 / 右键 / 中键 / 侧键1 / 侧键2 / 滚轮 / 合计
    · 「寿命」列＝当前档案从启用日起该键用量 ÷ 额定寿命，两位小数，颜色随用量渐变：
      绿(用得少)→黄→橙→红(接近额定寿命)；档案里没填该键寿命的显示「—」
    · 寿命百分比每 30 秒刷新一次（点击计数仍正常实时更新）
    · 合计行的寿命＝加权：用得最多的键权重 0.6，第二、三名各 0.2（最常点的键最容易坏）
    · 合计（数值）＝表中显示的各点击键相加，不含滚轮；隐藏的侧键不计入合计行
    · 右上角「总点击次数」仍是全部 5 个点击键的真实总数（含隐藏键）
    · 滚轮上/下滚合并计一格，单独一行，不计入任何点击合计、不参与加权
    · 侧键可在设置里隐藏（隐藏只是不显示，后台照常计数）
  近七天每日点击：最近 7 天每天总点击量条形图，今天那条蓝色高亮
  首页黄框提示（有则显示，可点击）：
    · 未开管理员权限：「⚠️ 未开启管理员权限，可能无法记录游戏内点击」
    · 未开自启动：「⚠️ 未开启开机自启动…点此去「设置」开启」（点它会跳到设置页）
  「以管理员身份重启」按钮保留在首页底部（避免找不到）
  快捷键：按 Esc 可把窗口隐藏到后台（等同点右上角叉号）

【右下角托盘图标】
  左键单击（双击也行）：打开/唤回窗口（窗口被其他程序挡住时会自动置顶一下）
  右键单击           ：鼠标右上方弹出菜单 → 控制面板（打开窗口） /
                        切换鼠标档案（二级菜单选择档案） / 退出程序（终止运行）
  鼠标悬停 ：显示「档案名｜今日 N 次｜总计 N 次」（缩写形式）
  提示：Windows 11 默认把新图标收进「^ 隐藏的图标」里，拖到任务栏上就会常驻显示

【窗口关闭行为】
  点窗口右上角叉号 → 直接隐藏到后台（不再弹询问框），程序继续记录
  想真正退出：托盘右键菜单 →「退出程序」，或窗口里的「退出程序」按钮
  隐藏后随时用托盘图标（左键单击）把窗口叫回来

【设置页】
  按键显示与命名：
    · 侧键1、侧键2 可勾选显示/隐藏；左键、右键、中键固定显示，不可隐藏
    · 隐藏只是不在首页表里显示，后台仍然照常计数，随时可开回
    · 每个键都能重命名（留空则恢复默认名）
    · 滚轮：上/下滚合并记录（滚一格计 1），固定显示，不计入合计与总点击
  开机自启动：勾选后登录时后台静默运行；未勾选时本行右侧显示 ⚠️ 图标提示。
    · 首次开机自启且你从未手动开关过时，程序会默认帮你开启，避免找不到入口
    · 有管理员权限 → 注册 Windows 计划任务（登录触发、最高权限），开机静默不弹 UAC，游戏内也统计
    · 无管理员权限 → 退回注册表 Run（能开机启动，但游戏内可能不计数）
    · 自启动路径会自愈：换文件夹/换电脑后手动打开一次即恢复；多副本时最后运行的接管自启动
  备份与恢复：
    · 每天首次保存自动备份一份到「备份位置」，保留最近 7 份
    · 「立即手动备份」按时间戳另存一份；「从备份恢复」可选择某份还原
    · 备份内容包含计数、设置与全部鼠标档案；恢复前会先自动备份当前数据，不怕误操作
    · 「更改…」可自定义备份文件夹位置（留空=默认 数据目录\backups）
  数据文件：显示当前数据文件完整路径，「打开数据文件夹」直达（从首页移到了这里）

【鼠标档案页】
  每行一只鼠标，显示：名称（微动型号）、使用中/添加日期，以及寿命使用量两行
  · 「＋ 新建档案」：换鼠标时建一条，填鼠标名称、微动型号（选填）、各键额定寿命
    · 额定寿命按键单独填写，单位是「万次」（如填 2000 表示 2000 万次）；留空＝不统计该键
    · 支持回车保存、Esc 取消
  · 「使用此档案」切换当前；「编辑」随时改；「删除」为红字，点击后需二次确认，
    且强制等待 3 秒「确认删除」才可点击（防误删）；至少保留一个档案；
    删除只移除该档案的名称/寿命/显隐配置，历史点击数据一律保留
  · 每个档案独立保存今日、近 7 天、总计和寿命数据；切换档案后整套数据随之切换
  · 旧版共用数据升级时，历史点击会全部归入升级前当前档案；其它档案从 0 开始
  · 寿命用量 = 从该档案起始日起各键累计 ÷ 额定寿命，颜色绿→黄→橙→红随用量渐变
  · 寿命百分比每 30 秒刷新一次，减少高频界面重算
  · 寿命为额定参考值：以官方数据为准，受使用环境影响极大
  · 各键的显示/隐藏与重命名跟随各档案独立保存（不同鼠标侧键配置可不同）

【游戏里统计不到点击？】
  带内核反作弊的游戏（例如明日方舟：终末地，ACE 反作弊）以高权限运行，普通权限的程序
  收不到它们的鼠标输入，这是 Windows 的 UIPI 限制。解决：以管理员身份运行本程序
  （首页「以管理员身份重启」按钮，未提权时下方有黄框警告）。状态栏若出现
  「⚠ 钩子疑似被拦截」，说明当时钩子确实没收到事件，日志在 tray.log。

【点击数据存在哪】★ 重要
  点击记录不在程序文件夹里，而是在你的「文档」下：
     C:\Users\<你的用户名>\Documents\鼠标点击次数记录\鼠标点击记录（配置文件，勿删）.json
   · 好处：更新版本、重装、甚至删掉整个程序文件夹，记录都不会丢；换新版本直接用新 exe 覆盖旧的
   · 鼠标名称、档案、设置都写在这一个文件内部，文件名固定不变（不随鼠标名改，避免改名丢数据）
   · 设置页「打开数据文件夹」= 直接打开这个文件夹；备份/换电脑 = 复制这一个 json 文件
   · 每天一条记录、自动保存（最多丢 3 秒数据），初次点击后自动生成
   · 若「文档」被 OneDrive 同步，这个文件会跟着上云（属于文档目录的正常行为）
   · 「文档」不可写时依次退到 用户目录 → 程序目录\config\ → 程序目录 →
     %LOCALAPPDATA%\鼠标点击次数记录\，界面照常工作不会丢数据
   · 老版本数据文件叫「点击数据记录（勿删！！！）.json」或 data.json，
     本版本第一次启动会自动把它搬进新文件名，计数一条不丢；
     更早分开的「滚轮上滚/下滚」两列也会自动合并成一个「滚轮」总数

【目录结构】
  鼠标点击次数记录.exe   主程序（单文件，免安装，不依赖 Python）
  使用说明.txt           本文件
  config\                程序自带的辅助文件（整个删掉/替换也不影响点击数据）
   ├ icon.ico            托盘与窗口图标
   ├ 启动.bat            等价于双击 exe
   ├ 设置开机自启动.bat / 取消开机自启动.bat   一键开关自启动
   └ 更新日志.md         版本变更记录
  说明 1：数据、备份、日志都在「文档\鼠标点击次数记录」里，程序目录只是可执行文件壳。
  说明 2：界面按系统缩放（125%/150%）等比放大，文字不发虚；换电脑（分辨率/缩放不同）自动适配。

【资源占用】
  使用 Windows 底层鼠标钩子 (WH_MOUSE_LL)，回调只做计数并入队，不阻塞鼠标输入；
  空闲时 CPU 占用 ≈ 0%（开机后累计 CPU 时间通常不到 1 秒），内存约 50 MB，
  窗口隐藏后同样保持监听。界面刷新单次约 1.5 毫秒，实时同步不影响电脑性能。
  任务管理器里会看到两个同名进程，这是单文件 exe 的正常现象（一个是解包引导，
  一个是主程序），只有主程序带窗口。

【隐私说明】
  本程序只统计各键按下次数与滚轮格数，不记录鼠标位置、点击内容、窗口标题或任何输入信息。

【卸载】
1. 双击 config\取消开机自启动.bat（或先取消设置页的「开机自动启动」勾选）
2. 托盘右键 →「退出程序」（或点窗口里的「退出程序」按钮）
3. 删除整个程序文件夹；想保留记录就只删文件夹，数据在「文档\鼠标点击次数记录」里
   （连记录也不要了，就把那个文件夹一并删掉）
